Chi sono

Developer orientato alla qualità, all’innovazione e alla realizzazione di soluzioni digitali efficaci

Sono Pietro Gancitano, Web Application Developer. Mi occupo dello sviluppo di applicazioni web e software con particolare attenzione alla user experience, alla struttura del codice e alla qualità delle soluzioni.

Ho competenze nello sviluppo frontend e backend, nella progettazione di API REST, nella gestione di database, nell’integrazione di sistemi e nella realizzazione di applicazioni complete, dall’idea alla distribuzione.

Lavoro con tecnologie come Java, Python, JavaScript, C, C#, PHP, SQL, NoSQL, Spring, Angular, React, Django, oltre a strumenti per la gestione di sistemi e applicazioni aziendali.
